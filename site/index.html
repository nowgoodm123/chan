Two ways to work, one agent

The same engine drives the interactive terminal chat and the browser app. Switch whenever you want.

terminal

Interactive CLI

Streaming chat, tool output, approval prompts, a slash command palette, /connect and resumable sessions. Works over SSH.

browser

Local web UI

Chat from a polished UI on 127.0.0.1:4731. Attach images for vision models, upload files, approve risky commands, edit providers.

tools

Real coding tools

read, write, edit, list, glob, grep, bash, webfetch and a todo list. Path-safety checks and dangerous-command guards built in.

models

Any model, one config

DeepSeek, OpenAI, Anthropic, OpenRouter, Groq, Qwen, Moonshot, GLM, Ollama, LM Studio, vLLM — plus any compatible endpoint.

sessions

Persistent sessions

Conversations, todos and token usage are saved per workspace. Resume from the CLI or the browser.

safe

You stay in control

Approval modes: auto, ask before risky commands, or deny shell access. Token-protected web server, local-only by default.

Install

chan_code needs Node.js 18.17 or newer. There are no npm dependencies to download.

# PowerShell
git clone https://github.com/nowgoodm123/chan_code.git
cd chan_code
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1

# or link it yourself
npm link
chan init --provider deepseek
$env:DEEPSEEK_API_KEY = "sk-..."
chan serve --open
# macOS
git clone https://github.com/nowgoodm123/chan_code.git
cd chan_code
bash ./scripts/install.sh
chan init --provider deepseek
export DEEPSEEK_API_KEY="sk-..."
chan serve --open
# Linux
git clone https://github.com/nowgoodm123/chan_code.git
cd chan_code
bash ./scripts/install.sh
chan init --provider deepseek
export DEEPSEEK_API_KEY="sk-..."
chan serve --open
# from a checkout (not yet published to npm)
npm install -g .
chan --version
chan --help

# or run it directly
node bin/chan.js run "summarize this repo"

The browser UI is part of the product

Run chan serve and open the URL. Use the terminal when you want, the browser when you need to look at things.

  • Drop in screenshots of errors, designs, or dashboards — vision models can read them.
  • Upload files to .chan/uploads and mention the path; the agent can read them.
  • Watch every tool call as a collapsible card with timing and output.
  • Approve dangerous commands straight from the chat.
  • Manage providers — base URL, model and API key — without editing JSON.
  • Remote access safely with --host 0.0.0.0 --token <secret>.

Bring your own model

Two wire protocols are supported: OpenAI-compatible chat completions and Anthropic messages. Tool calling and streaming work on both.
